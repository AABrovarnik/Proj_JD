# Рабочие правила проекта

- Для длительной работы с проектом сначала прочитай `SESSION_STATE.md`, затем сверь фактическое состояние через `git status` и нужные файлы. Состояние в журнале может устареть.
- После существенного этапа обновляй `SESSION_STATE.md`: выполненное, текущий этап, изменённые файлы, открытые проблемы и ближайший следующий шаг. Не заявляй успешную проверку, если она не запускалась в текущем этапе.
- Не записывай в журнал API-ключи, токены, пароли, персональные данные или содержимое договоров.
- Перед передачей результата следуй `docs/ЧЕК_ЛИСТ_ПЕРЕД_СДАЧЕЙ.md`.
