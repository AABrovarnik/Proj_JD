# Changelog

## v0.1.0 — 2026-10-14

### Added
- Локальный MVP `ЮрОтдел` с веб-интерфейсом для анализа договоров аренды.
- Отдельные страницы `Анализ` и `Настройки`.
- Авторизация администратора (JWT), локальное хранение токена в UI.
- Загрузка и обработка документов `PDF/DOCX`.
- Извлечение текста (`pdf-parse`, `mammoth`).
- Выбор LLM-провайдера: `OpenAI`, `Alice`, `Local Mock`.
- Настройка модели и дополнительного промпта из интерфейса.
- Экспорт результатов в `JSON` и `CSV`.

### Changed
- Интерфейс обновлён в пастельной голубо-салатной гамме.
- Результаты анализа отображаются в карточках с контрастной подсветкой рисков.
- Введён статус `unclear` в результатах анализа.
- Расчёт итогового `score` перенесён на серверную сторону.

### Prompting / Compliance
- Добавлен базовый шаблон промпта по ТЗ (раздел 11).
- Добавлен уточняющий шаблон (под следующий этап refine-раундов).
- Ограничено влияние пользовательского `additionalPrompt` (не может менять формат/ограничения).

### Validation
- Добавлена серверная проверка цитат: неподтверждённые цитаты помечаются предупреждением,
  а статус `found` может понижаться до `unclear`.

### Security / Publishing
- Подготовлен `.env.example` с рекомендуемыми профилями:
  - Strong: `openai / gpt-6.1-sol`
  - Budget: `openai / gpt-6-luna`
- Из репозитория исключены тестовые файлы договоров аренды (`docs/договоры_Аренды`, zip).

### Known limitations
- OCR для сканов пока не подключён.
- Нет фоновой очереди и многоарендности.
- Уточняющие multi-round проходы (1+до4) ещё не внедрены.
